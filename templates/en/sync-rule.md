- **Pull before every request, and save when it ends.** This project syncs across computers (`sync.auto`). At the start of every request, run `npx --no-install excudo sync --pull` before reading or changing the memo. Finish with `npx --no-install excudo save "<what changed>"`, which also pushes. If the pull stops on uncommitted changes, run `excudo save` first. If it stops on a conflict, resolve it with plain git and never discard either side. If the remote or the Drive folder cannot be reached, tell the owner and continue with the local memo; the next `excudo save` or `excudo sync` sends it.
